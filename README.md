# IPHW Rate Calculator

Online-style IPHW Rate Calculator — **Designed & Developed by Amir Hamza**.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` (and optionally `IPHW_RATE_SOURCE.xlsx`).
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save. GitHub will provide the live URL.

## Deploy on Render
This is a static website, so no backend is required.

1. Push this folder to a GitHub repository.
2. In Render, create **New → Static Site**.
3. Connect the GitHub repository.
4. Build Command: leave empty.
5. Publish Directory: `.`
6. Deploy.

The calculator is self-contained and includes the IPHW Rate A/B and ODA data needed for offline/browser calculation.
